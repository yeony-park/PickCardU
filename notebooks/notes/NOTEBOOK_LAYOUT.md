# 노트북 폴더 구성

폴더 정리일: 2026-10-21. 사용자 요청으로 기존 파일을 이동하고 호출·링크 경로를 조정했다.

- `notebooks/`: 실험 `.ipynb` 45개.
- `notebooks/scripts/`: 기존 실험 실행·평가·검증 `.py` 93개.
- `notebooks/notes/`: 기존 설명·계획 문서와 이 구조 안내.
- `notebooks/data/`: 기존 입력·캐시·결과. 기존 실험 데이터 파일은 이동·재작성하지 않았다.
- `docs/report/`: 비교 HTML 보고서. 이동 파일을 가리키는 링크만 수정했다.

저장소 루트에서 실행하는 명령은 `python -B notebooks/scripts/<실행기>.py` 형식이다. 노트북은 기존 위치에서 열며 필요한 코드만 scripts에서 불러온다.

## 보존과 복구

[이동 전 원본 압축](../data/00_notebook_layout_migration/20261021T012319/original_files.tar.gz)과 [이동 대응표](../data/00_notebook_layout_migration/20261021T012319/migration_manifest.json)에 Git 미추적 파일을 포함한 이동 전 원본, 원래 경로·해시·수정시각, 새 경로를 기록했다. 이전 커밋만으로 미추적 자료가 복구되는 것은 아니다.

복구가 필요하면 먼저 이후 변경을 확인한 뒤 대응표의 파일만 원래 위치로 되돌리고, 수정 전 내용은 원본 압축에서 복원한다. 광범위한 git reset/clean이나 기존 실험 데이터 덮어쓰기는 하지 않는다.

## 검증 범위와 과거 봉인 기록

Python 파일의 프로젝트 루트 계산·모듈 로딩·데이터 경로, 노트북의 코드 호출, 설명 문서와 보고서 링크를 조정했다. 이전 실험 파일을 보호하는 경로 목록에는 scripts/notes를 포함했다. 검색·청킹·평가 알고리즘과 유료 호출 설정은 바꾸지 않았다.

기존 노트북 출력·실행 횟수와 실험 결과 JSON, 입력 계약, 비용 원장, 과거 코드 해시는 역사 기록으로 보존했다. 코드 셀의 경로를 바꿨다고 저장 출력을 새 실행 결과로 취급하지 않는다. 전체 실험이나 유료 API는 재실행하지 않았다.

**과거 코드 경로·해시를 봉인한 실행기는 새 위치의 수정된 코드를 기존 계약으로 재실행하는 것을 거절할 수 있다.** 이 검사를 우회하거나 과거 봉인값을 덮어쓰지 않았다. 당시 실행의 원본은 압축에서 확인할 수 있으며, 이후 실행은 새 경로/코드 버전을 명시한 별도 계약으로 시작해야 한다.

오프라인 검증 기록은 [폴더 정리 검증 결과](../data/00_notebook_layout_migration/20261021T012319/verification.json)에 보관한다. 21개 테스트 파일의235개 검사가 통과했다. 네트워크 연결을 차단해 새 API 요청이 나가지 않게 했다.

검증 중 처음 사용한 /tmp 임시 경로는 기존 출력 범위 제한에 걸렸고, 문서에 지정된 실험 내부 임시 위치로 수정했다. 또한 DB 테스트4개의 모듈 상대 데이터 경로를 수정해 건너뜀 없이 실행했다. 기존 테스트의 공용 합성 캐시 갱신도 발견해 원본 SHA-256과 수정시각으로 복원하고, 해당 테스트가 임시 캐시만 사용하도록 격리했다. 복원 증명은 이번 정리 기록의 cache_recovery_proof.json에 있다. 테스트 임시 산출물은 최종적으로 /tmp에 분리했다.
