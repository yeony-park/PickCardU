# 55–59 구조화 순차 검색 원인 진단·보완 계획

2026-10-22 사용자 승인. 52 개발40문항의 benefit 순차36/40 대 비구조화31/40 결과는 유지한다. 54 사전검증 실패는 보존한다. 이번 목적은 구조화 조회, 필요한 근거 확보, 생성 오류를 분리하고 보완하는 것이다.

## 고정 범위

- 새 검색 구조는 운영 benefit 프로필+S→U, 운영 parent-child 프로필+S→U 두 개뿐이다. 추가 병렬/S_ONLY/U 답변 비교는 없다. 기존 데이터의 읽기 전용 분석은 가능하다.
- 구조화 결과가 있으면 해당 카드 안에서 원질문으로 U를 한 번 수행한다. 결과0건이면 원래 카드·발급사 범위에서 U를 한 번 수행한다. 요청마다 별도 검증 LLM을 추가하지 않는다.
- 운영 코드/OCR 검증기/원본 JSON/PDF/DB/색인/52~54 코드와 원자료는 변경하지 않는다. 복사 DB의 변경은 등록 database-manager가 담당한다.
- 새 컬럼·오타 보정·동의어 확장·출력 스키마 확장은 제외한다. 미지원은 명시한다. 모델 gpt-6-luna/medium, 출력2400, parent bundle안최대5원문청크를 유지한다.
- HTML은 결과 검토 후 직접 작성한다. notebook은실험순서와결과, scripts는재개/공통검증에필요한최소책임만소유한다. helper의필요성은관련노트북에설명한다.

## 실행 순서

1. **55 원인 진단(API0)**: 52의280개 검색·실제API입력·답변과54의96추출을 원문/JSON/rawDB/derived/QueryPlan과 대조한다. 원문사실단위로 직접요구·중요조건·부가정보·불확실을 구분한다. 기존52판정은변경하지않는사후개발진단이다.
2. **56 구조화 보완**: 56A는저장동일plan과수동확인조건을원본/복사DB에적용해DB원인분리. 결정적일반규칙으로교환/적립·명시무실적·금액기준/단위/기간/관계를보완하고전변경판정을양음방향원문검토한다. 56B는37문서근거질문의동일명시필터짧은/상세74표현×기존/보완parser×3회=444추출을각DB에동일적용한다. 무실적threshold0은카드가요구하는최소실적없음이며사용자실적/결제액0이아니다. unknown→0금지. 같은카드AND·원범위·DB오류구분을회귀검사한다.
3. **57 근거 보완(API0)**: 40질문×두SEQ프로필에서A기존근거/B공통조건추가를비교한다. B는기존카드·순위·근거를보존하고같은카드FTS/BM25에서원질문+고정문구`전월실적 한도 횟수 서비스 선택 제외 조건`으로조회한다. 원문제목/경로가고정조건키워드를포함한구역을기존BGE로정렬하고동점chunk_id사전순으로최대2개추가한다. gold fact ID/정답페이지는선택에사용하지않는다. 기존5+추가2=최대7근거/카드,전체64000bytes,원문단위통째추가만허용. parent한bundle안최대5청크와답변근거7개는별개다. 예산증가비교임을공개한다.
4. **58 생성 요인 비교**: H05,H08,H11,H13,H19,H21,H23,H24,D36,D38,D39,D40의12문항×두SEQ프로필×근거A/B×기존/보완prompt×2회=192답변. 원문필수근거완전제공진단군12×두prompt×2회=48추가,합계240/최대480물리답변요청. 진단군에는정답문장/채점주석없이원문발췌만주고후보성능분모에서제외한다. 모델·출력스키마·2400토큰은고정한다.
5. **59 신규 확인**: 설정고정뒤새32질문을원문정답·필수조건과함께동결한다. 추천24=단일혜택12/복수혜택8/발급사·실적조건4,상세8=실적한도횟수3/예외채널2/계산1/부정·확인불가2. 공통추출96,두SEQ프로필×32×3=192답변/최대384물리답변요청. 새질문U기준선은없으므로운영개선량·효과확인·품질SLA통과·운영준비완료는주장하지않는다. 같은106문서의기술적품질·안정성확인이며새문서독립holdout이아니다.

## 사실·평가 계약

- 평가단위는chunk ID가아닌카드·혜택·조건·수치·단위·기간·예외범위를보존한원문사실이다. 다른카드값대입금지. 실제질문이요구하는유효카드한개의완전성및전체추천의정확성을따로평가한다.
- 직접요구및추천의적용가능성을바꾸는중요조건만필수분모에넣는다. 부가정보미열거는실패로만들지않는다. 원문불확실은별도공개하며성공으로세지않는다. Bliss5교환을earn양성정답으로넣지않는다.
- 필수근거회수율=입력에지원된필수사실/원문확인필수사실. 검색결과와실제serialized입력을각각계산한다. 완전근거확보율=질문의필수사실전부확보한질문/평가가능질문.
- 조건부반영률=입력에지원되고정확히답한필수사실/입력에지원된필수사실. 종단충족률=정확히답한필수사실/전체원문필수사실. 둘을함께보고한다. 분모0=N/A.
- 카드Hit/MRR,질문PASS,근거없는추가주장,중요오류,범위위반도유지한다. 주집계는질문macro와질문별W/L/T다. 반복·설정행을독립질문으로합산하지않는다.
- 각판정에는원문PDF SHA/page/발췌,검색결과·실제입력·답변SHA,지원/부재/모호/해당없음상태와사유를결속한다. 미판정은미완료이며임의자동PASS금지.
- 새규칙·gold·fact ID·정답페이지·원문평가주석이검색선택또는답변입력으로흘러가면실험실패다. 58원문완전근거진단군만명시적예외다.
