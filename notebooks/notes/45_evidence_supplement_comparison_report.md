# 45. 카드·순위 고정, 동일 예산 원문 근거 보완 비교

## 왜 실행했는가

구조화 검색은 후보 카드와 일치 fact를 찾지만 현재 순차 방식은 카드 범위만 비구조화 검색에 전달한다. 같은 카드의 핵심 혜택·조건 근거가 최종 답변 입력에서 빠지는지, 검증된 원문 근거를 보완하면 답변이 개선되는지 확인했다. 원문 연결 검사를 먼저 실행하고 이후 근거 패키지만 비교했다.

## 바꾼 것과 고정한 것

A는 42번 S_THEN_U의 저장 카드·순위·근거·답변이다. B는 입력 카드와 순위를 고정하고 카드별 첫 A 근거를 보존한 뒤, 완전 충족 그룹의 fact에 연결된 원문 청크를 조건별로 번갈아 채웠다. 잔여 자리는 기존 근거로 채웠다. 카드별 최대 5개와 질문 포함 64,000 UTF-8 bytes 상한이 동일하다. 원문 중간 절단·재청킹·파서/임베딩/검색/BGE 신규 호출은 없다. 답변 생성은 기존 gpt-6-luna/medium, prompt/schema, 2400 출력 상한과 기존 재시도 정책을 유지했다.

**이 비교는 고정 카드·동일 예산의 근거 재구성이다.** 추가만 된 11쌍과 기존 근거가 교체된 7쌍을 구분한다. 교체 행의 차이를 순수 추가만의 인과효과로 해석하지 않는다. LLM 최종 추천의 누락/순서 변화는 결과이며, 고정한 것은 검색 카드 목록/순위다.

## 주의점

106개 Upstage 문서의 OCR/구조화 통과 가정과 불완전한 제목 계층을 유지했다. 이번 연결은 원좌표를 수리하지 않는 보수적 full-line/fragment/관계 범위 검사다. 제외를 OCR 오류나 운영 검증기 실패로 단정하지 않는다. 31번 기존 매핑의 target/value 포함만으로 근거를 인정하지 않았다. 여러 청크는 원문에서 같은 fact 관계가 확인되는 경우에만 연결했다.

42번의 개발 질문 48개(양성44·진단4)를 재사용했다. A는 과거 저장 답변이고 B는 신규 확률 생성이므로 시점/생성 변동이 섞인다. 독립 holdout·사람의 블라인드 검증·통계적 우월·운영 채택 결과가 아니다. 방식명을 가린 쌍대 검토지만 검토자의 이전 세션 맥락은 남아 있다. 전체 논리 조건은192개이며 동일 입력의 답변 재사용은 반복 독립 실행이 아니다.
