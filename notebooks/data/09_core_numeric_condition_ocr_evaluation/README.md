# 09_core_numeric_condition_ocr_evaluation

이 폴더의 현재 직속 구조를 기록한다. 파일 역할은 이름과 현재 구조에서 확인 가능한 범위로만 설명한다.

## 구성

현재 로컬 구조를 기준으로 한 직속 항목이다. 캐시·비밀값·대용량 실행 산출물은 목록에서 제외한다.

| 항목 | 설명 |
|---|---|
| `runs/` | 실행 ID별 critical fact OCR 평가 산출물을 보관. |
| `api_original_repeatability_summary.json` | 집계 요약 산출물. |
