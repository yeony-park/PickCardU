지표 의미

  • CER: 정답 전체 문자와 OCR 텍스트 간 편집 거리 비율. 낮을수록 문자·공백·순서 차이가 적습니다.
  • WER: 단어 단위 편집 거리 비율. 낮을수록 단어 누락·치환·삽입이 적습니다.
  • 내용 토큰 Recall / Precision: 정답 단어가 OCR에 보존된 비율 / OCR 단어 중 정답에 있는 비율입니다. 순서 변화에는 CER/WER보다 덜 민감합니다.
  • 순서 유사도: 전체 문자열의 상대적 순서가 정답과 유사한 정도입니다.
  • 필드값 Recall: 수동으로 정한 혜택·조건·한도 등의 값이 OCR 원문에 존재한 비율입니다.
  • 필드 전체 일치: 페이지의 수동 필드값이 하나도 빠지지 않은 페이지 비율입니다.

결과 해석

  • PaddleOCR: CER/WER는 세 엔진 중 가장 낮지만, 내용 토큰 Recall 23.30%, 필드값 Recall 64.33%, 필드 전체 일치 10.00%입니다. 일부 짧은 출력이 맞더라도 카드 혜택·조건·한도 원문이 대량 누락되어 주 OCR 후보로 판단하기 어렵습니다.
  • Vision OCR: 내용 토큰 Recall 89.48%, 필드값 Recall과 필드 전체 일치가 모두 100.00%입니다. 핵심 필드는 보존했지만, 전체 텍스트 Precision 66.50%와 높은 CER/WER는 정답에 없는 토큰 또는 읽기 순서 차이가 적지 않음을 뜻합니다.
  • Upstage: 내용 토큰 Recall 89.55%, 필드값 Recall과 필드 전체 일치가 모두 100.00%입니다. 이 표본에서는 Vision보다 순서 유사도가 소폭 높지만, Precision 66.69% 및 높은 CER/WER가 있어 단독 우위를 확정할 근거는 부족합니다.

중요: 정상 출력이라면 OCR 결과의 텍스트량도 정답 페이지와 대체로 비슷해야 합니다. 정답보다 지나치게 짧으면 누락, 지나치게 길면 표·헤더·푸터 중복, 다른 페이지 혼입, 또는 수동 전체 전사 누락을 의심해야 합니다. 따라서 ‘더 많은 텍스트를 읽었다’는 사실만으로 성능이 좋다고 해석하지 않습니다.

다음 단계

  1. 이상 페이지 우선 대조: CER/WER가 특히 높거나 텍스트 길이 차이가 큰 Woori, Hana, NH 페이지부터 원본 PDF·수동 전체 정답·각 엔진 출력을 나란히 확인합니다.
  2. 오류 원인 분류: 각 차이를 정답 전사 누락, 지정 페이지 외 텍스트 혼입, 요소·표 중복, 읽기 순서 차이, 실제 문자 오인식, 실제 내용 누락으로 기록합니다.
  3. 정답셋 보정: 원본에는 있으나 수동 전체 정답에 빠진 문구만 보완합니다. OCR에 맞추어 정답을 바꾸지 않습니다.
  4. 어댑터 보정 후 재계산: 다른 페이지 혼입·중복 출력이면 엔진별 원문은 보존하고 평가용 페이지 추출 어댑터만 수정한 뒤 동일 정답셋으로 다시 평가합니다.
  5. 엔진 선택: 보정 후 전체 텍스트 Recall/Precision, 필드 보존, 실제 오류 사례, 비용·속도를 함께 비교해 Vision과 Upstage 중 주 엔진 및 교차 검증 엔진을 결정합니다.

해석 시 주의

전체 페이지 전사는 사람이 원본을 보고 작성했지만, 작은 문구·공백·읽기 순서 차이는 CER/WER에 크게 반영됩니다. 따라서 엔진 선택은 CER/WER만으로 확정하지 않고, 필드값 보존과 실제 오류 사례를 함께 봐야 합니다.
