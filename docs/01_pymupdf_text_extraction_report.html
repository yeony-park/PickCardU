왜 이 테스트를 했나

원본 PDF에 바로 쓸 수 있는 텍스트 레이어가 있는지 먼저 확인해 OCR 필요 범위를 정하려 했다.

이 테스트로 무엇을 확인하려 했나

PyMuPDF 추출문이 카드 혜택 조건과 표 내용을 얼마나 보존하는지 확인했다.

PyMuPDF 텍스트 추출 결과 보고서

대상 데이터: 카드 상품설명서 PDF 106개 · 실행 환경: Conda skn25 · PyMuPDF 1.28.0 · 작성일: 2026-07-20

결론: PyMuPDF는 텍스트 레이어 존재 여부를 빠르게 판별하고 다수 문서의 본문을 추출하는 데 유용합니다. 그러나 이 데이터셋에서는 빈 페이지, 제어 문자, 글꼴 인코딩 매핑 오류가 확인되어 OCR을 완전히 대체하는 단일 추출기로 사용하기에는 부적합합니다.

1. 검사 범위와 기준

원본 PDF data/documents/raw/의 106개 파일을 대상으로 PyMuPDF page.get_text("text")를 실행했습니다. 문서 단위 판정 기준은 다음과 같습니다.

  • 페이지 사용 가능: 공백 제거 후 20자 이상이며 읽을 수 있는 문자 비율이 70% 이상
  • 텍스트 레이어 사용 가능: 총 200자 이상이고 사용 가능 페이지 비율이 80% 이상
  • 부분 사용 가능: 일부 페이지만 추출 가능
  • OCR 필요: 사용 가능한 텍스트 페이지가 없음

텍스트 레이어 사용 가능으로 분류된 88개 PDF는 페이지 표식을 포함한 PyMuPDF 원문 텍스트로 별도 저장했습니다.

9. PyMuPDF와 Vision OCR 원본 기준 성능 평가

기존의 출력 간 일치도 비교를 삭제하고, 원본 PDF를 직접 확인해 만든 정답셋으로 교체했습니다. 대상은 실제 카드 정보가 있는 10개 PDF의 각 1페이지입니다. 각 페이지마다 전체 텍스트 정답과 필드 정답을 모두 만들고, 두 엔진에 같은 평가를 실행했습니다.

평가 지표와 정규화

  • 정규화 CER: 문자 단위 편집 오류율입니다. 낮을수록 원문 텍스트에 가깝습니다. 엔진별 종합값은 10페이지 오류율의 단순 산술평균입니다.
  • WER: 단어 단위 편집 오류율입니다. 누락·삽입·순서 변경을 함께 반영하며 낮을수록 좋습니다. 엔진별 종합값은 10페이지 오류율의 단순 산술평균입니다.
  • 내용 Recall / Precision: 순서를 제외한 단어 내용의 보존률입니다. 원문 단어가 빠지지 않았는지와 불필요한 단어가 추가되지 않았는지를 봅니다.
  • 읽기 순서 유사도: 사람이 읽는 원본 순서와 추출 순서의 유사도입니다. 청킹 전 문맥 결속을 보는 보조 지표입니다.
  • 핵심 사실 부분문자열 일치 / 토큰 보존률: 전체 텍스트 페이지별로 직접 라벨링한 할인율·금액·조건 등 3개 사실이 완전 문구 또는 구성 토큰 수준에서 보존됐는지 확인합니다. 부분문자열 일치는 표현 순서에 민감하므로 단독 결론 지표가 아닙니다.
  • 필드 값 Recall: 10개 페이지에 직접 라벨링한 연회비·할인율·한도·브랜드 등 60개 값을 추출 결과에 포함했는지 확인합니다. 값 존재 여부만 보는 지표이므로, 표의 행·열 관계나 필드명과 값의 연결 정확도는 평가하지 않습니다.
