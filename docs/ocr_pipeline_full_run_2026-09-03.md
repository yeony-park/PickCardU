이번 실행이 답하려는 질문은 다음과 같다.

- 원본 PDF 106개를 Luna와 Upstage에 모두 전달해 OCR 원응답을 확보할 수 있는가?

## 6. 구조화 JSON 단계 예상 비용

OCR 페이지 JSON 생성은 공급자 응답을 로컬 코드가 정리하므로 추가 Luna 호출이 없다. 그다음 OCR 텍스트를 혜택 구조화 JSON으로 바꾸는 `structure` 단계는 Luna를 사용한다. Luna OCR 결과와 Upstage OCR 결과를 독립적으로 구조화하므로 106개 전수 기준 최대 212회 호출한다. 이후 `normalize`와 `validate`는 로컬 코드로 실행한다.

현재 동일 설정으로 완료된 1개 문서·2개 lane 표본의 Luna 구조화 비용은 약 `$0.127`이었다. 이를 단순히 106개로 확대하면 약 `$13.5`지만 표본이 한 개뿐이므로 **추정이며 신뢰도가 낮다**. 각 호출의 출력 상한까지 고려한 중단 방지용 잔액은 `$30~35`가 안전하지만, 실제 전수 비용으로 확정할 수는 없다.

전수 구조화 전에 문서 길이가 다른 소규모 표본의 실제 토큰과 시간을 측정해 예상치를 보정하되, 그 표본 실행을 전수 완료로 간주해서는 안 된다.
