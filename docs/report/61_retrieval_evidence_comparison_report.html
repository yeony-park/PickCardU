순차는 구조화 조회 결과가 있으면 그 카드 안에서 원질문으로 비구조화 검색을 한 번 수행하고, 0건이면 원래 카드 범위에서 한 번 수행한다. 별도의 전체 비구조화 결과를 합치지 않는다. 구조화 혜택 본문을 검색어나 추가 답변 근거로 삽입하지 않는다.

동일 106문서·질문·원질문 벡터·세 반복의 추출 조건을 공유했다. 운영 benefit / parent-child 청킹, 상위3카드, 카드당 근거5, parent 묶음5, 본문 64,000바이트 및 재정렬 토큰 경계를 유지했다. 문서 청크의 신규 임베딩과 답변 생성은 없다. 운영 코드·원자료·OCR 검증기는 수정하지 않았다.
