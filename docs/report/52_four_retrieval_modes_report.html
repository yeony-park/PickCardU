52. 최초 네 검색 방식 비교의 중단 기록

2026-10-22 · 개발 실험 · 조회 규칙 오류로 비교 부적격 · 최종 방식 선정 없음 · 운영 미반영

답변 API를 호출하기 전에 잘못된 구조화 조회 규칙을 확인했다. 검색 조건 280개 중 239개를 저장한 시점에 실행을 중단했다. 이 자료로 검색 방식이나 청킹의 성능 우열을 확정하지 않는다. 원래 코드·manifest·추출값·부분 결과·임베딩 응답은 보존한다.

실험 목적과 비교 조건

구조화 단독(S_ONLY), 비구조화 단독(U), 구조화 후 카드 범위 안에서 비구조화 검색하는 순차(SEQ), 구조화 근거와 독립적인 비구조화 결과를 합쳐 BGE로 재정렬하는 병렬(PAR)을 비교하려 했다. 순차에 별도 전체 비구조화 경로를 겹치지 않는다. 구조화 단독은 청킹과 무관하게 공통 40조건, 나머지는 benefit·parent-child 각각 40조건씩이다. 질문·원래 발급사/상품 범위·운영 검색 설정·모델·청킹·입력 한도는 고정했다.

확인한 오류와 근거

기존 실험용 조회 코드는 요청 대상이나 그 별칭이 exceptions 문자열에 등장하면 혜택 행 전체를 거절했다. 예외란에는 제외 규칙뿐 아니라 포함 특례, 허용 결제경로, 실적 산정 제외, 신규 발급 예외도 함께 저장되어 있다.

실제 삼성 iD ON 커피 행에는 스타벅스 등의 대상과 30% 혜택이 있고, 예외란에는 “스타벅스의 경우, 사이렌오더 결제건도 혜택 제공”이라는 포함 특례가 있다. 커피를 대상으로 한 통제 조건에서 기존 숫자·종류 평가는 참이지만 예외 문자열 검사 때문에 최종 행 판정은 거짓이 됐다. 원문은 상품안내서 2쪽이며 DB의 해당 사실 ID는 fact_24b5b46a45ce25ef5fe467cb다.

‘고속버스 제외’에 ‘버스’가 포함된다는 이유로 일반 버스 혜택을 제거하는 사례도 있다. 이는 검색 대상 전체의 제외와 하위 업종·결제경로의 제외를 구분하지 못한 문제다. 원래 H01 추출에는 별도로 ‘커피전문점’의 문자 일치 범위와 기간 표현의 한계가 있으므로 이 규칙 하나를 고치면 모든 질문이 해결된다고 주장하지 않는다.

저장된 51번 추출의 고유 조건 51종과 3,403개 사실을 이용한 오프라인 반사실 비교에서 이 검사 제거는 187개 조건·사실 조합, 서로 다른 75개 사실의 판정을 바꿨다. 전체 문맥·출처를 분류한 현재 차분에서는 대상 전체가 제외되는데 새로 통과하는 사례를 확인하지 못했다. 이 판정은 기존 OCR 통과 가정과 출처가 연결된 DB 필드를 사용하며, 독립적인 OCR 재검증이나 미래 모든 문장의 안전성 보장은 아니다. 전체 차분과 75개 사실의 분류·원출처를 보존했다.

현재 결과와 자원

검색 기록 239/280조건을 저장했으며 그중 34/40질문은 일곱 검색 조합을 모두 마쳤다. 답변은 0/280조건으로 미실행이다. 조건 수는 구조화 단독을 청킹별로 중복 계산하지 않은 논리 분모다. 실행 수가 높다는 것은 완료 정도를 뜻하며 정확도나 통과율이 아니다. 예를 들어 잘못된 조회로 근거가 비어 있어도 검색 함수 실행 기록은 한 조건으로 남는다.

새 임베딩 요청은 1회, 비용은 저장 usage 기준 $0.000005080이다. 임베딩 40문항 중 이전 캐시에 없는 8개 질문만 전송했다. 46–51번을 합친 확인 비용에 이를 더한 누적 확인 비용은 $0.272201310이다. 기존 HTTP 520 한 건의 실제 비용은 미확인이며 승인된 상한 $0.003127까지 차감한 예산 계상액은 $0.275328310이다. 조직의 실제 청구액은 미측정이다. 단가는 공식 가격표와 임베딩 가격을 따른다.

답변 완료 시간·첫 토큰·브라우저 표시 시간은 미측정이다. API 답변 미실행을 0초 응답으로 표기하지 않는다. 두 차례 외부 SIGTERM 중단의 정확한 원인은 확인되지 않았다. 이후 정상 중단 구간은 개별 저장 지점과 자원을 분리했다. 처음 두 중단 구간 전체 CPU·최대 RSS는 미측정이며, 부분 검색 시간에 캐시가 섞여 있어 운영 지연 우열로 해석하지 않는다. 실행 구간 설명과 구간별 자원 기록을 참고한다.

검증 범위와 후속 처리

앞서 오프라인 회귀 검사 29개는 통과했으나 포함 특례와 제외 문장의 이 구분을 다루지 못했다. 따라서 그 통과를 구조화 검색 의미 정확성의 인증으로 사용하지 않는다. 새 수정에는 포함 특례·실제 제외·명시 제외 대상·수치/횟수·같은 카드 AND·기차/전기차 경계·원문 보존 차분을 추가하고 독립 리뷰 후 유료 실행에 진입한다.

동결된 이 실행을 덮어쓰지 않고 수정 조회를 별도 52번 분기로 보존할 예정이다. 원래 51번 1회차 LLM 추출값은 그대로 유지하며 수정 조회로 다시 얻은 결과만 별도 기록한다. 검증된 동일 질문 임베딩·원래 U 결과·BGE 점수 캐시는 출처와 입력을 대조해 재사용한다. SEQ·PAR·구조화 단독은 수정 조회로 다시 구성한다. 운영 코드·OCR·원본 DB를 수정하는 작업은 수행하지 않았다.

최종 정리

이번 최초 실행은 조회 규칙 오류 때문에 비교 결과로 채택하지 않는다. 최종 검색 방식·청킹·근거 전달 방식의 선정은 아직 없다. 답변 비용 지출 전에 오류를 확인했고 새 확인 비용은 임베딩 약 0.000005달러다. 원래 결과를 보존한 뒤 수정 분기의 52번 비교, 53번 순차 근거 추가, 54번 신규 질문 반복 확인 순서로 이어간다.
