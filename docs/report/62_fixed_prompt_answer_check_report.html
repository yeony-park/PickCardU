실제 상위 카드 모집합을 원문으로 검토해 카드별 조건을 답변 생성 전에 고정했다. 다른 유효한 카드·혜택 경로를 허용하고 불확실한 관계는 성공으로 채우지 않았다. 같은106문서의 개발평가이며 독립 사람의 맹검·새 문서 검증은 아니다. 세 반복은 같은40질문의 반복이지 서로 독립인120질문이 아니다.

판정 보완: 독립 검토에서 자유서술에만 나온 카드와 비교·배제 카드의 조건 감사가 필수 검증에서 빠질 수 있음을 확인했다. 유료 실행의 고정 코드를 보존한 채 별도 오프라인 검증을 추가했다. 전체 본문을 카드별/공통 안내로 빠짐없이 배정하고 모든 실제·비교 카드의 원문·입력·조건·답변 인용을 결속한다. 비교 카드는 감사를 받지만 추천 성공과 조건 반영률 분모에서는 제외한다. 사용한 기준을 바꿔 점수를 높이는 작업이 아니다.

유지할 파이프라인 정의는 구조화 결과가 있으면 그 카드 안에서 원질문 U 한 번, 없으면 원래 범위 U 한 번 → 검색 근거 → LLM 답변이다. 이것은 구현·비교한 실험 흐름이며 운영에 새 코드를 반영했다는 뜻은 아니다. 다음 검증은 실제 선택 카드의 실적·한도 관계가 누락되는 사례와, 완전근거가 주어져도 중요한 조건을 빼는 사례를 분리해 각 한 요소씩 바꾸는 비교가 필요하다. 범용 G05 퇴행과 N24의 다른혜택 요율 혼동을 방어조건에 남기고, 새 운영 설정 확정 전 새 문서/독립 사람 검토도 구분해 진행해야 한다. 추가 유료 실험은 이번 완료 범위에 포함하지 않는다.
