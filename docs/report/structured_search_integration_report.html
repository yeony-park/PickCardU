왜 실행했고 무엇을 확인했나

73번의 기존 순차(DB3 정규화·기존 조회 판정·카드 목록만 전달)를 현재 운영 라이브러리에 이식했다. 질문은 후보 카드 선정에 사용하고 답변에는 해당 카드의 기존 비구조화 본문만 전달한다. 답변 품질이 카드 적중만으로 보장되는지, 범위를 지키며 기존 릴리스와 공존하는지 확인하는 개발 검사다. 독립 확인셋이나 전체 코퍼스 품질 확증이 아니다.

변경한 것은 고정 QueryPlan 추출, DB3 SQL 조회, allowed_card_keys 범위, 별도 structured.sqlite 릴리스와 선택적 usage.structured다. benefit/parent-child 청킹·검색 가중치·깊이·BGE 경로·답변 프롬프트·출력 상한은 유지했다. 이번 최초 DB와 두 프로필의 청크/벡터 입력은 보존된 Upstage 스냅샷이다. 현재 Luna 활성 릴리스와 공급자가 다른 DB를 결합하지 않았다.
