중단 원인과 재개 조건

첫 실행은 커널의 시스템 메모리 부족으로 종료 코드137을 받았습니다. 4,012토큰을 포함한5쌍 점수 비교에서 원래 저장 점수와 문서1개 호출 차이는 허용0.0001 이하였고 신규 API0회였습니다. 어댑터·프로토콜·기준 캐시 해시와 기존22행·41응답을 묶은 재개 계약은 유지합니다. 첫 재개는 신규 모델 호출 전에 여유 검사에서 멈췄습니다. 이후 준비 검사가 통과한 실행을 시작했습니다.

첫 계약 이후 6개 답변을 추가 완료했고 현재 80개 답변이 남았습니다. 최신 실행은 메모리 여유 부족으로 중단됐으며 모델 점수 호출43회를 관측했습니다. 순간 최고RSS는2419776KiB였고 이를 재개 전 필요 여유 계산에도 반영합니다. 모델 자체 또는 입력 토큰 오류로 판정하지 않습니다. 다른 프로세스·운영 코드·원문·청크 길이·토큰 제한은 바꾸지 않았습니다. 할당 해제 진단에서 반환한 약112MiB만으로는 충분한 여유를 입증하지 못했습니다.
