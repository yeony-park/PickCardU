변경 변수는 묶음 생성 정책뿐입니다. 기존 최대5개, 최대4개, 토큰 확인 최대5개/8개를 비교합니다. seed는 필수이며 원래 관련 청크→다른 후보 순서로 전체 청크를 선택합니다. 너무 긴 seed는 명시 실패로 남깁니다. 개별 청크 길이·본문·4096 문서 한도·8192 질문과 문서 입력 한도·BM25/벡터0.6/0.4·Top50/D20/Top3·BGE와 최종 카드당 근거 최대5개를 고정했습니다. 최대8개는 재정렬용 묶음 상한이며 답변 근거8개를 보장하지 않습니다.

초기 재실행에서 Q10의 Chroma 근사 검색 후보 순위가 달라져 엄격 재현 검사가 중단되었습니다. 최종 카드·근거는 같았지만 내부 후보 변동이 있었습니다. 성공했던33번의 BM25/vector 전체 후보를 고정하고 실패했던 Q05/Q28 U만 현재 운영 검색기에서1회 생성했습니다. 이 신규 후보에서도 기존 실패를 재현했습니다. 각 질문의 정책 비교는 동일 후보이며 전체 평균은 과거·현재 후보가 섞인 기술 진단입니다. 매 조건마다 검색 엔진을 새로 실행한 전체 경로 평가로 해석하지 않습니다.

개발20개에서 설정을 선택·해시 동결한 뒤 나머지13개를 실행했습니다. 모두 이전에 결과를 확인한 질문이므로13개는 post-selection verification / 설정 선택 후 확인이며 독립 확증·holdout이 아닙니다. 전체 행렬은 사후 탐색 결과입니다.
