65번에서는 직접 질문을 해결했어도 묻지 않은 실적·한도·예외를 빠뜨렸다는 이유로 전체 답변이 미통과될 수 있었습니다. 이번에는 직접 요청 충족, 실제로 말한 사실의 정확성, 실제 입력 지원, 추가 설명의 충실도를 분리했습니다. 실적을 묻지 않은 커피 카드 추천에 실제 할인 카드를 추천했다면 실적 생략만으로 실패시키지 않습니다. 반대로 “실적 없이 할인”이라고 잘못 확정하거나 다른 혜택의 할인율을 가져오면 실제 오류로 남깁니다.
