56. 구조화 검색의 값 정규화와 조건 추출을 분리해서 비교

56A의 복사 DB 보완과 오프라인 비교를 완료했다. 56B의 질문 표현·조건 추출 비교는 실행 전 동결 단계다. 아래는 답변 생성 품질 개선율이 아니다.

왜 실행했나

원문에 전월실적 조건이 없다고 명시되어 있는데도 DB 파생값이 unknown(확인 불가)으로 저장되는 사례를 확인했다. 올바른 LLM 조건 max_spend_krw=0을 만들어도 이 상태에서는 조회되지 않는다. 이는 기차와 철도 같은 표현 차이와 구분되는 DB 값 해석 문제다.

질문은 두 가지다. 같은 검색 조건에서 DB만 보완하면 결과가 달라지는가? 같은 뜻의 짧은 질문과 상세 질문에서 기존·보완 조건 추출은 얼마나 일관적인가? 먼저 DB를 비교하고 이후 추출 비교를 진행한다.

무엇을 바꾸고 무엇을 고정했나

원본 30번 SQLite와 문서·사실 JSONL을 읽고 별도 복사본만 수정했다. 문서106개, 사실3403개, 기존 별칭22개, 원문 JSON·사실 ID·문서 관계·스키마는 유지했다. 운영 코드, OCR 검증기, 원본 PDF/JSON/DB/색인과 청킹은 변경하지 않았다. 새 동의어·오타 보정·컬럼을 추가하지 않았다.

지표 안내: Changed facts(변경 사실 수)는 전체3403행 중 실제 파생값이 바뀐 행 수다. 예를 들어 커피 혜택과 영화 혜택이 같은 카드에 있으면 서로 다른 행이다. 많을수록 좋은 지표가 아니며 원문에 맞는 변경만 허용한다. 21/3403은 검색 정확도나 오류율이 아니다.

올리브영 원문은 이용금액에 비율을 곱한 결과를 리워드 적용 금액으로 설명한다. 월3만원/20만원은 구매금액 상한으로 단정할 수 없어 기존 지급 혜택 한도값을 유지했다. 중간 계산 단계라는 이유만으로 지급 한도에서 제외하면 잘못된 보완이 된다.

어떤 순서로 확인했고 결과는 어땠나

  1. 21개 변경 결정을 원문 PDF의 결정 문구 또는 수동 이미지 관찰에 연결했다. 텍스트 근거16개와 이미지 근거5개에 이미지 검토 기록6쪽이 연결된다. 이 검사는 변경한 파생값의 의미만 확인하며 전체 OCR·raw 필드 검증이 아니다.
  2. 원본·복사본의 해시, SQLite integrity/FK, 불변 열, 별칭, 문서 관계, DB 열과 파생 JSON 및 JSONL의 일치를 검사했다. 원본 해시 유지, 불일치0, 두 번째 정규화 실행의 추가 변경0이었다.
  3. 52번 저장 조건40개를 그대로 양 DB에 적용했다. 결과 카드 목록이 바뀐 질문은0개였다.
  4. 54번의 보존 추출96개도 그대로 양 DB에 적용했다. B01의 세 반복만 카드 목록이 바뀌었고 모두 쿠팡 와우카드를 찾았다. 54번의 미실행 답변은 평가하지 않았다.
  5. 변경21행에 직접 연결한 수동 조건을 검사했다. 무실적7행은 불일치→일치, 교환1행은 잘못된 일치→불일치, 비지급 한도13행 중12행은 잘못된 일치→불일치, 나머지1행은 기존에도 다른 사유로 불일치였다.
지표 안내: Matched(조회됨)는 고정 조건을 만족하는 카드가 있는지를 뜻한다. 검색 순위의 Hit@3/MRR@3와 다르다. 예를 들어 ‘전월실적 없이 쿠팡 적립’에서 쿠팡 와우카드가 반환되면 조회된 것이다. 일반적으로 많을수록 좋은 수치는 아니며 잘못된 양성이 줄어드는 것도 올바른 보완이다. 같은 질문의3회 반복을3개 독립 질문으로 세지 않는다. 40질문과96추출의 분모도 합산하지 않는다.

B01 원질문: 쿠팡·쿠팡이츠·쿠팡플레이를 자주 쓰는데 전월실적 없이 적립되는 카드 찾아줘. LLM 조건을 고치지 않고 DB만 보완했을 때 세 반복 모두 결과없음에서 해당 카드 조회로 바뀌었다.

따라서 무실적 상태 오류는 실제 조회 실패 원인이다. 다만 기존40질문의 카드 목록은 그대로였으므로 이 보완만으로 기존 검색·답변 품질이 얼마나 오르는지는 확인되지 않았다.

56B 비교 설계와 실행 상태

원문 근거37질문을 짧은/상세74문장으로 구성하고, 기존/보완 추출 각각3회씩 총444추출을 수행한다. 각 추출 조건을 원본·복사 DB에 동일하게 적용한다. 질문쌍은 상품·발급사 범위와 명시 조건, 상황 수치의 구분을 API 전에 수동 검토하고 각 문장 해시와 조건 서명을 동결한다. 서명 일치 검사는 수동 검토 기록의 일관성을 확인하며 자동 의미 증명이 아니다. 고정 스키마로 완전히 표현하지 못하는 제약은 별도 기록한다.

단계 비용 상한은 두 추출 방식을 합쳐0.50달러, 승인된 누적 상한은8달러다. 새 사용량 미확인 실패가 있으면 중단한다. 같은 질문의 표현·반복을 먼저 평균낸 후37질문 단위로 비교하며, 검색 조건 정확도와 DB 조회 유무를 구분한다. 현재 이 보고서에는 56B 결과를 포함하지 않았다.
