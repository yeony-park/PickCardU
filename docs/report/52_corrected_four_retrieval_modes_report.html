무엇을 비교했고 무엇을 고정했는가

  • S_ONLY — 구조화 단독: 질문 조건 추출 → DB 조회 → 일치 사실 전체를 BGE로 정렬 → LLM 답변. 조회0건이면 비구조화 검색을 추가하지 않는다. 청킹별로 중복 실행하지 않은 공통40조건이다.
  • U — 비구조화 단독: 원질문 → 운영 vector+BM25 및 재정렬 → LLM 답변. 원래 명시된 카드·발급사 범위는 유지한다.
  • SEQ — 순차: DB 결과가 있으면 해당 카드 안에서 원질문으로 U를 한 번 수행한다. 결과가 없으면 원래 범위에서 U를 한 번 수행한다. 별도 전체 U 결과를 겹쳐 합치지 않는다.
  • PAR — 병렬: 직접 조회한 구조화 사실과 원래 범위의 독립 U 결과를 합쳐 단위 ID 중복을 제거하고, 전체 근거 단위에 공통 BGE 재정렬을 적용한 뒤 답한다. (S→U)+U가 아니다.
