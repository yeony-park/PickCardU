추가 소개 카드 89행의 별도 검토

점검 대상 첫 카드 외에 답변이 언급한 카드 89행(질문·카드 조합 42개)을 확인했다. 미검토는 0행, 원문 조건의 불확실이 남은 것은 9행, 발견 사항이 있는 것은 33행이다. 조건 누락 27건, 모호함 5건 외에 부적합 추천·관계 범위 오류 등이 있었다. 한 행에 여러 발견이 있어 건수와 행 수는 다르다.

benefit 순차의 추가 카드 10행에서는 이번 감사의 발견 사항이 없었다. parent-child 순차의 추가 카드 10행 중 4행에는 발견 사항이 있고 1행은 원문 불확실이 남았다. 이는 첫 카드까지 포함한 전체 답변 오류율이 아니다. 질문에 맞지 않는 대안을 그 사실을 밝히며 소개한 경우도 따로 분류했으므로 모든 발견을 오답이라고 합산하지 않는다.

52번의 원문상 카드 유효성 판정 재사용과 이번 답변 조건 검토를 분리했다. 80행은 52번의 이전 수동 원문 판정·PDF 해시를 재사용했다. 이 80행의 출처를 모두 이번의 정확한 페이지 인용/이미지 결속 계약으로 재검증한 것은 아니다. 나머지 9행의 직접 PDF 인용은 이번 계약으로 검사했다. 두 출처 방식의 증거 강도를 동일하게 읽으면 안 된다.

답변 해시·카드 귀속은 89행 모두 결속했다. 개인 한도 조회 불가 질문에서 든 공개 상품 예시는 개인 승인내역 조회로 취급하지 않았다. 이 감사만으로 검색 누락인지 생성 누락인지 확정하지 않는다. 전체 감사와 불확실·사유

노트북 전체 코드 셀을 실행해 280행 주판정과 추가 카드 89행의 결속 검사를 통과했다. 평가 계산의 회귀 검사 20개가 통과했다. 추가 감사 전에 계산한 1차 초안은 별도 보존했으며, 브랜드 범위 설명 관련 3행의 답변 지원 판정을 정정한 후 최종 재계산했다. 신규 지표는 평가지표 문서에 정의했다.

최종 정리와 다음 단계

이번 단계에서 검색이나 답변 성능 자체를 바꾸지는 않았다. 카드 Hit만으로는 놓치던 근거 회수와 답변 반영을 분리했고, 명시 무실적의 파생값 문제·공통조건 누락·혜택 관계 손실·생성 오류가 함께 있음을 확인했다. benefit 순차가 이번 진단의 가장 높은 수치를 보였지만 일부 질문에서는 비구조화보다 낮아졌고 parent-child는 수치·사용자 예시 질문에서 근거 대비 답변 충족이 낮았다.

채택한 것은 사실별 진단 계약이며 운영 설정은 변경하지 않았다. 이 단계는 파라미터 탐색이 아니므로 새 운영 후보를 확정하거나 설정을 폐기하지 않는다. 기존 benefit 순차 개발 후보를 유지하면서 56번의 복사 DB 정규화·조건 추출 분리 비교, 57번의 같은 카드 공통조건 보완, 58번의 생성 요인 비교, 59번의 새 질문 기술 확인으로 이어간다. 비용은 새 API 0달러이며 시간 계측은 오프라인 분석에 한정된다. 추천의 사실 분모 차이, 원문 불확실 7사실·추가 감사 9행, 추가 감사 80행의 과거 원문 판정 재사용, 독립 사람 검수 부재는 남아 있다.
