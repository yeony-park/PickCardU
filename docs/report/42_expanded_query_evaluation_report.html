확증 범위: 새48질문(수치16·카드상세16·의미16),양성44·일반/모호/자료미확인4입니다. 같은106카드 자료이며 독립 비공개 holdout이 아닙니다. 정답은 최대3카드의 원문검토된 partial anchor(부분 정답 기준)입니다. 목록 밖의 유효 카드도 자동 점수에서는 미포함으로 잡힐 수 있으므로 승패와 모든 방어 위반의 원문을 따로 확인합니다. 74개 예비 anchor 혜택의 관계를 Codex와 읽기 전용 독립 검토자가 확인해72개를 유지하고2개를 평가 정답에서 제외했습니다. 원본 DB/OCR은 수정하지 않았습니다. 이번 Q_EXPAND_U는 실제 추출 조건 재표현과 고정 DB 범주 표현 추가 정책의 평가입니다. 같은 질문을 재생성한 반복 실험은 아니며 실행별 분산은 미측정입니다.
