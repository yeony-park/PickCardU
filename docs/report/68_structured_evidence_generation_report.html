왜 실행했나

구조화 DB에 있는 내용을 못 찾는 문제와, 전달한 내용을 LLM이 잘못 사용하는 문제를 분리하기 위해서다. 67번에서 선택한 DB4·명시 명사 후보 매칭·기존 조건 추출기를 공통 적용했다. 이번 비교에서는 프로필·질문·회차별 카드 목록·순위·기존 비구조화 근거를 고정했다. 각 청킹의 운영 검색 프로필은 그대로 유지했다.

구조화 양성이면 후보 카드 범위에서 원질문으로 벡터+BM25 검색을 한 번 수행하고, 0건이면 원래 범위에서 한 번 수행한다. 별도 전체 비구조화 결과를 병합하지 않는다. 프로필별 36검색 중 양성 범위 검색 32, 원래 범위 복귀 4였다. 총72 논리 검색이며 실제 신규 비구조화 검색은28건, 나머지는 동일 질문·벡터·프로필·범위의 검색 재사용이다. 답변은432개 모두 별도 생성했다.
