5. 무엇을 놓쳤나

  • C18 · 실제 계산 오류: benefit 수정 r2는 1만5천 원 전체에 20%를 곱해 3천 원이라고 답했다. 입력과 원문에는 할인 전 대상 이용금액이 1회 1만 원까지라고 있다. 계산상 최대 할인액은 1만 원 × 20% = 2천 원이며 공유 월한도의 잔여분이 충분해야 한다.
  • C12 · 카드 간 실적 조건 전이: benefit 수정 r2는 세 카드 모두 국내 이용금액 30만 원이 필요하다고 묶었다. FLEX의 원문과 입력은 국내외 합산이다. 해당 카드 자체와 질문한 30만 원 조건은 찾았지만 추가 설명이 틀렸다.
  • C09 · 서로 다른 혜택 한도 전이: parent 수정 r1은 삼성 iD ON의 커피와 스트리밍이 같은 통합 월한도를 쓴다고 설명했다. 원문은 커피 자동맞춤 할인과 스트리밍 할인에 각각 다른 한도를 둔다.
  • C16 · 결제 범위 불확실: 원문의 ‘온라인(간편결제 등)’ 제외를 ‘온라인·간편결제’ 제외로 표현한 경우, 오프라인 간편결제까지 전체 제외한다는 의미인지 모호했다. 확정 오답과 구분해 엄격 통과에서는 제외했다.
  • C18 · 계산과 조건 설명의 구분: parent 수정 r1은 ‘최대 2천 원’ 계산은 맞았지만 월 잔여한도 조건을 직접 설명하지 않아 고정된 질문 기준의 조건부 설명이 부족했다. 이를 3천 원 계산 오류와 같은 오류로 세지 않았다.

새 수정 순차 48개 중 기술 실패는 0건, 확인된 주장 오류는 3건, 불확실한 주장만 있는 답변은 7건이다. 나머지 미통과 1건은 사실 자체는 맞지만 직접 요구의 잔여한도 설명이 빠진 경우다. 미요청 연회비를 빠뜨렸다는 이유로 탈락시키지 않았다. 다만 C14 한 답변은 입력에 삼성카드 연회비가 있는데도 연회비를 확인하기 어렵다고 말해 입력 사용 여부에서 별도 표시했다.
