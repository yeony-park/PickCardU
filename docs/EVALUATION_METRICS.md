# 평가 지표 정의

## OCR 진단 지표

### Token Jaccard — 단어 집합 겹침 비율

- **계산 대상과 분모:** 같은 페이지의 Luna 단어 집합과 Upstage 단어 집합의 합집합 크기를 분모로 사용하고, 교집합 크기를 나눈다. 한 문서 안에서는 페이지별 값을 평균하고, 전수 비교에서는 다시 비교 가능한 문서들의 값을 평균하는 document-macro 방식을 사용한다.
- **방향:** 높을수록 두 OCR 결과가 비슷하다.
- **통과 기준:** 단독 통과 기준으로 사용하지 않는다. OCR 차이를 찾는 진단 지표다.
- **예시:** 양쪽 모두 `편의점 10% 할인`을 읽으면 해당 단어가 겹쳐 값이 높아진다.
- **한계:** 둘 다 같은 글자를 잘못 읽어도 높을 수 있고, 표의 읽기 순서나 Markdown 표현 차이만으로 낮아질 수 있다.

### Upstage 숫자 기준 Luna 숫자 재현율 — 숫자 일치 비율

- **계산 대상과 분모:** Upstage가 읽은 서로 다른 숫자 개수를 분모로 하고, 그중 Luna에도 있는 숫자 개수를 분자로 사용한다.
- **방향:** 높을수록 Upstage의 숫자를 Luna도 많이 읽었다.
- **통과 기준:** 단독 통과 기준으로 사용하지 않는다. 숫자 차이가 큰 문서를 검수 대상으로 찾는 지표다.
- **예시:** Upstage가 `전월 30만원, 월 1만원`을 읽고 Luna도 `30`, `1`을 읽으면 100%다.
- **한계:** Upstage가 휴대전화 화면, 마스킹 카드번호 또는 장식 숫자를 잘못 읽으면 Luna가 정확해도 낮아질 수 있다. Upstage는 gold가 아니다.
