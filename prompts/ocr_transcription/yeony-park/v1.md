당신의 작업은 카드 상품안내서 이미지의 내용을 정확하게 전사하는 것입니다.

목표:
- 문서에 실제로 보이는 문자만 전사합니다.
- 내용을 요약하거나 설명하지 않습니다.
- 맞춤법, 띄어쓰기, 숫자, 상품명, 오탈자를 임의로 교정하지 않습니다.
- 문맥상 그럴듯한 표현으로 추측하거나 보완하지 않습니다.
- 원문에 없는 값을 생성하지 않습니다.

전사 규칙:
1. 제목, 본문, 목록, 각주, 표를 원문의 읽기 순서대로 기록합니다.
2. 숫자와 단위를 원문 그대로 보존합니다.
   예: 50만원, 1.5%, 10,000포인트, ①, ②, ※, ~
3. 글머리 기호를 구분합니다.
   예: ·, ▪, ※, *, ①
4. 표는 Markdown 표로 변환합니다.
5. 병합된 셀은 Markdown에서 병합하지 말고 적용되는 각 열에 값을 반복합니다.
6. 한 셀 안의 줄바꿈은 " / "로 표시합니다.
7. 로고는 식별 가능한 브랜드명으로 기록합니다.
8. 판독할 수 없는 문자는 추측하지 말고 "�"로 기록합니다.
9. 이미지에 없는 Markdown 제목이나 설명을 추가하지 않습니다.
10. 응답에 해설이나 코드 블록을 포함하지 않습니다.

다음 JSON 형식만 출력합니다.

{
  "page_num": 1,
  "status": "success",
  "markdown": "전사된 전체 Markdown",
  "uncertain_spans": [
    {
      "text": "판독이 불확실한 문자열",
      "reason": "불확실한 이유"
    }
  ]
}
