속도 해석

Keyword p50은 1.71ms, vector/hybrid는 약 223ms입니다.

현재 vector 후보 계산은 SQLite vector 전체를 Python으로 순회합니다. 운영 성능 비교 전 pgvector/HNSW 같은 ANN index가 필요합니다.

질의 embedding batch latency 1,827.685ms는 표의 core-search latency에서 분리했습니다.

평가 한계현재 질문은 전체 106문서 중 6문서의 gold context로 만든 130개 seed이며, relevance도 해당 gold context 중심으로 제한돼 있습니다. 자연어 paraphrase·복합조건·비교·답 없음·보유카드 1/3/5장 hard negative와 수작업 relevance 판정을 추가해야 운영 결정을 확정할 수 있습니다. 정답 발급사·카드 필터 결과는 라우팅 정답을 미리 사용한 진단치입니다.
